<h2>Current Development</h2>

<h3>Turtle Gravity | LiveDVR</h3>

<p>Inventor, Lead Developer & Architect</p>

<p>Turtle Gravity is a proprietary software platform for operating linear television infrastructure online, in-house, or across offline-capable environments.</p>

<p>Its LiveDVR technology enables prerecorded media files to maintain a persistent live state, allowing operators to create continuously programmed television experiences without conventional broadcast infrastructure.</p>

<p>Applications include:</p>

<ul>
<li>Digital out-of-home media and electronic signage</li>
<li>Retail, hospitality, and entertainment venues</li>
<li>Independent television and radio networks</li>
<li>OBS streaming and creator broadcasting</li>
<li>Branded product and promotional television</li>
<li>Educational and institutional media networks</li>
<li>Private and offline-capable media infrastructure</li>
</ul>

<p>Development areas include electronic program guides, automated programming, remote management, REST interfaces, synchronized media experiences, and file-based linear streaming.</p>
